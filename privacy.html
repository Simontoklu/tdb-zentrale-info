Privacy Policy

Last updated: October 14, 2026

TDB Zentrale is an internal tool of the music label Thousanddollarbills. It is used only by the label owner to publish videos to the label's own accounts. This policy explains which data the tool uses.

1. Data the tool receives

  • Google / YouTube: an OAuth access token and refresh token, the channel ID, channel name and handle, and the status of uploaded videos. Scopes: youtube.upload and youtube.readonly.
  • Instagram: an access token, the account ID and username, and the status of published Reels.
  • TikTok: an access token and refresh token, the account ID (open_id), display name and username, and the status of uploaded videos. Scopes: user.info.basic, user.info.profile, video.upload and video.publish. When the publish screen opens, the tool also requests the creator info of the connected account (nickname, avatar, available privacy options, comment/duet/stitch settings, maximum video length). This creator info is only displayed on the publish screen and is not stored.

The tool only accesses the label's own accounts. It does not collect, read or store any data about other users, viewers or followers.

2. How the data is used

The data is used only to upload and publish the label's own videos and to show the owner whether an upload worked. It is not used for advertising, profiling or any other purpose, and it is never sold or shared.

3. Storage and security

Tokens and account data are stored only on the owner's own computer, in a file that only the owner's user account can read. They are not uploaded to any server or cloud service. To publish a Reel, Instagram fetches the video file from a temporary link that exists only for the few minutes of the upload.

4. Google API Services

TDB Zentrale's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses the YouTube API Services; see also the YouTube Terms of Service and the Google Privacy Policy.

5. Deleting data and revoking access

Disconnecting an account in the tool deletes its tokens. Access can also be revoked at any time:

  • Google: myaccount.google.com/permissions
  • Instagram: Settings → Website permissions → Apps and websites
  • TikTok: Settings → Security → Manage app permissions
